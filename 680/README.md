# Gardener-painter

N trees stand in a row and each must be painted white, blue or orange so that no two neighbouring
trees have the same colour. Count the number of possible colourings.

**Input** (`input.txt`): the number of trees N (1 <= N <= 50).
**Output** (`output.txt`): the number of colourings.

Examples: `3` → `12`.
