# Text shift

Given two strings of equal length, find the smallest number of positions the first string
must be cyclically shifted to the right to obtain the second one (shifting `abcde` right by
2 gives `deabc`), or report that it is impossible.

**Input** (`input.txt`): two lines of English letters of the same length (up to 10000).
**Output** (`output.txt`): the minimal shift, or `-1`.

Examples: `abcde` / `deabc` → `2`.
