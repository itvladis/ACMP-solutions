# Sum of maximum and minimum

A sequence of integers is numbered starting from one. Find the maximum among the elements
with even indices plus the minimum among the elements with odd indices.

**Input** (`input.txt`): from 2 to 2·10^5 integers on one line, each not exceeding 10000 in absolute value.
**Output** (`output.txt`): max{a2, a4, ...} + min{a1, a3, ...}.

Examples: `1 2` → `3`, `1 -2 3 -4 5` → `-1`.
