# Salads

A salad is a mix of two or more ingredients. Given N different ingredients, count how many
different salads can be made.

**Input** (`input.txt`): a positive integer N (N < 32).
**Output** (`output.txt`): the number of different salads.

Examples: `3` → `4`, `4` → `11`.
