# Prime factorization

Write the integer N as a product of primes.

**Input** (`input.txt`): a natural number N (2 ≤ N ≤ 2^31 - 1).
**Output** (`output.txt`): the prime factors in non-decreasing order separated by `*`.

Examples: `5` → `5`, `30` → `2*3*5`.
