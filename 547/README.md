# Period of a fraction

Find the length of the pre-period and the length of the period of the decimal expansion of 1/n.

**Input** (`input.txt`): n (2 ≤ n ≤ 10^6).
**Output** (`output.txt`): two numbers: the pre-period length and the period length.

Examples: `3` → `0 1`, `5` → `1 1`, `28` → `2 6`.
