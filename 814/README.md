# Goldbach conjecture - 2

Count the number of ways to write a given number x as a sum of exactly two primes. Sums that differ
only in the order of the terms are counted once.

**Input** (`input.txt`): a natural number x (x ≤ 10000).
**Output** (`output.txt`): the number of such representations.

Examples: `4` → `1`, `10` → `2`, `11` → `0`.
