# Terrorist base

A plan of a base is given as an Nb×Mb grid of `#` (part of the base) and `.` (sand), and a
satellite map of the desert is an Nd×Md grid of the same symbols. The base may be located
at any position of the map where every `#` of the plan lands on a `#` of the map; sand
cells of the plan may cover anything, since extra rocks could have been brought in.
Count the possible positions of the base (the plan is not rotated).

**Input** (`input.txt`): Nb and Mb (1 ≤ Nb, Mb ≤ 20) and the plan, then Nd and Md (1 ≤ Nd, Md ≤ 100) and the map.
**Output** (`output.txt`): the number of possible positions.

Examples: the three samples from the statement give `4`, `6` and `4`.
