# Weighing

There are N identical-looking coins, one of which is fake and slightly heavier than the others.
Using a balance scale without weights, find the minimum number of weighings that always identifies
the fake coin.

**Input** (`input.txt`): the number of coins N (2 <= N <= 10^9).
**Output** (`output.txt`): the minimum number of weighings.

Examples: `2` → `1`, `3` → `1`.
