# Cells in a circle

A circle of real radius R is drawn on squared paper with cell size L, its centre placed at a grid
node. Count the cells lying entirely inside the circle.

**Input** (`input.txt`): a real R (0 ≤ R ≤ 25000, at most 9 digits after the point) and a natural L.
**Output** (`output.txt`): the number of whole cells inside the circle.

Examples: `5 1` → `60`.
