# Sequence 4

The k-th term of a sequence is A_k = k! · 2^k for k = 1, 2, 3, ... Find the sum of the first
N terms modulo M.

**Input** (`input.txt`): two integers N (1 ≤ N ≤ 10^4) and M (2 ≤ M ≤ 10^9).
**Output** (`output.txt`): the sum of the first N terms modulo M.

Examples: `5 10` → `2`, `10000 2` → `0`, `100 1000000000` → `909349562`.
