# Kayak trip

N people with known weights go on a kayak trip. Each kayak holds one or two people and
has a load limit of D kg. Find the minimum number of kayaks needed.

**Input** (`input.txt`): N and D (1 ≤ N, D ≤ 15000), then N weights (each not greater than D).
**Output** (`output.txt`): the minimum number of kayaks.

Examples: `4 135 / 50 74 60 82` → `2`, `6 135 / 50 120 74 60 100 82` → `4`.
