# Election of priests

Every county belongs to a confederation patronized by one of 200 priests. Confederations
submit requests to switch from their current priest to a desired one; all requests are
applied simultaneously, and confederations without a request keep their priest. Output
the patron priest of every county after the re-election.

**Input** (`input.txt`): N (1 ≤ N ≤ 5000), then the current priest of each county, then M (1 ≤ M ≤ 200) and M pairs "current priest, desired priest".
**Output** (`output.txt`): the new priest of each county in order.

Examples: `7 / 1 1 5 3 1 5 1 / 2 / 5 1 / 1 3` → `3 3 1 3 3 1 3`.
