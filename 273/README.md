# Crossing out

Given a natural number N, count how many different three-digit numbers can be obtained by
crossing out some digits of its decimal notation.

**Input** (`input.txt`): a natural number N with up to about a hundred digits.
**Output** (`output.txt`): the number of distinct three-digit numbers.

Examples: `12` → `0`, `111111111110011111111` → `4`.
