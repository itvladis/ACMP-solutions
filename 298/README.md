# Shooter

A shooter stands at the origin; bullets pierce targets and hit everything along the ray of
the shot. Given the target coordinates, find the minimum number of shots needed to hit all
of them.

**Input** (`input.txt`): N (N ≤ 20), then N lines with integer coordinates X, Y (-10 ≤ X, Y ≤ 10).
**Output** (`output.txt`): the minimum number of shots.

Examples: `4 / 2 2 / -2 2 / -2 -2 / 2 -2` → `4`, `6 / 2 2 / -2 2 / -2 -2 / 2 -2 / 1 1 / -1 3` → `5`.
