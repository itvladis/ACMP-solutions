# Minimum path in a table

A player starts in the top-left cell of an N×M table and may only move right or down.
Every visited cell, including the first and the last, costs the number written in it.
Find the minimum total cost of reaching the bottom-right cell.

**Input** (`input.txt`): N and M (1 ≤ N, M ≤ 20), then N rows of M numbers from 0 to 100.
**Output** (`output.txt`): the minimum possible cost.

Examples: `3 4 / 1 1 1 1 / 5 2 2 100 / 9 4 2 1` → `8`, the 5×5 example → `11`.
