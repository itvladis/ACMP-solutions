# Fun with a divider

Dima measured the distance between every pair of given lattice points with a divider.
Determine how many different distances he got and list them.

**Input** (`input.txt`): n (2 ≤ n ≤ 50), then n lines with integer coordinates not exceeding 10^4 in absolute value.
**Output** (`output.txt`): the number k of distinct distances, then the distances in increasing order, one per line, with precision 10^-9.

Examples: `4 / 0 0 / 1 1 / 1 0 / 0 1` → `2 / 1.0 / 1.414213562373`.
