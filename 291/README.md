# Dictionary

Given a dictionary and a set of letters, count how many dictionary words can be composed
from these letters (each letter of the set can be used at most once per word).

**Input** (`input.txt`): N (0 ≤ N ≤ 1000), N distinct lowercase words, then the set of
letters (1 to 100 letters).
**Output** (`output.txt`): the number of words that can be composed.

Examples: `ant bee cat dog ewe fly gnu` with `bew` → `0`; the same words with `tancugd` →
`3`.
