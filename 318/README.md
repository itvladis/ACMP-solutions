# Next number

For a natural number N, find the smallest number greater than N that has the same number
of ones in its binary representation.

**Input** (`input.txt`): N (N ≤ 2^30).
**Output** (`output.txt`): the required number.

Examples: `1` → `2`, `2` → `4`, `3` → `5`.
