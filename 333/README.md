# Common digits

Given three natural numbers A, B, C, find the digits that occur in all three of them.

**Input** (`input.txt`): three natural numbers A, B, C (up to 10^80) separated by spaces.
**Output** (`output.txt`): the number of common digits on the first line and the digits themselves in increasing order on the second.

Examples: `1 2 3` → `0`, `12 13 14` → `1 / 1`, `1234 2345 3456` → `2 / 3 4`.
