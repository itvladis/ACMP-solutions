# Circles

What is the largest number of regions the plane can be divided into by N circles that all have
the same radius?

**Input** (`input.txt`): an integer N (0 ≤ N ≤ 33333).
**Output** (`output.txt`): the maximum number of regions.

Examples: `0` → `1`, `3` → `8`.
