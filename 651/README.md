# Transforming monocellulars

An organism consists of N cells and has to be turned into an organism of M cells.
In one operation you may either split every cell into P parts (multiplying the number
of cells by a prime P) or merge cells into groups of T (dividing the number of cells by
a prime T, only when it divides evenly). Find the minimal number of operations.

**Input** (`input.txt`): two integers N and M (1 ≤ N, M ≤ 10^9).
**Output** (`output.txt`): the minimal number of operations.

Examples: `2 36` → `3`, `32768 3` → `16`, `1434 1434` → `0`.
