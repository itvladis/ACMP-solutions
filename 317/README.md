# Santa's gifts

A toffee weighs X grams, a tangerine Y grams and a gingerbread Z grams. Count how many different
gifts (sets of these items) weigh exactly W grams.

**Input** (`input.txt`): four integers X, Y, Z and W (1 ≤ X, Y, Z ≤ 100, 1 ≤ W ≤ 1000).
**Output** (`output.txt`): the number of different gifts.

Examples: `10 25 15 40` → `3`.
