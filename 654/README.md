# Concert hall

A speaker's frequency response is split into N intervals with volumes A_i. An amplifier raises
the volume by 1 dB on a range of intervals from A to B, but only if all of them have the same
volume before it is applied. Find the minimum number of amplifiers needed to make all volumes equal.

**Input** (`input.txt`): N (1 ≤ N ≤ 200000), then N volumes (1 ≤ A_i ≤ 10^9).
**Output** (`output.txt`): the minimum number of amplifiers.

Examples: `3 / 1 3 2` → `3`, `4 / 1 2 4 2` → `5`, `5 / 3 1 4 1 1` → `6`.
