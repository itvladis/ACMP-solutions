# Patterns

A pattern is a string of digits and the symbols `a`-`g` and `?`. A digit stays itself, `a` can become
any of 0-3, `b` any of 1-4, and so on up to `g` (6-9), and `?` can become any digit. For two patterns
of equal length, count the digit strings that can be produced from both.

**Input** (`input.txt`): two patterns of the same length (at most 9), one per line.
**Output** (`output.txt`): the number of common strings.

Examples: `???` / `abc` → `64`, `???` / `000` → `1`, `abc` / `999` → `0`.
