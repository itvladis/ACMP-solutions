# Annual balance

An accountant may rearrange the digits of the expense a and of the income b (keeping each sign, and
without a leading zero in a nonzero number). Find the largest possible value of a - b.

**Input** (`input.txt`): two integers a and b (-10^9 < a, b < 10^9).
**Output** (`output.txt`): the maximum possible difference.

Examples: `18` / `10` → `71`, `1` / `-23` → `33`.
