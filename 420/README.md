# Chemical formula

A simplified formula of a substance is a sequence of element symbols (an uppercase letter,
optionally followed by a lowercase one). Two or more equal atoms in a row must be grouped:
the symbol is written once followed by the count (so `H2`, never `HH`). Check whether the
given string is a correctly written formula under these rules.

**Input** (`input.txt`): a string of digits and English letters, length 1 to 1000.
**Output** (`output.txt`): `YES` or `NO`.

Examples: `OHNaOHNa` → `YES`, `H2O` → `YES`, `HH` → `NO`, `CHC` → `YES`.
