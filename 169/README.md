# Shop

A person stands N steps away from a shop and each minute steps either towards the shop or away from it.
Count the ways to reach the shop in exactly K steps, arriving there only on the last step.

**Input** (`input.txt`): N and K (1 ≤ N ≤ K ≤ 37).
**Output** (`output.txt`): the number of ways.

Examples: `2 4` → `2`, `5 5` → `1`.
