# Flying saucers attack

A laser beam is the infinite straight line through two given points. Saucers are circles
given by center and radius. A saucer is destroyed if it has at least one common point with
the line. Output how many saucers are destroyed and their numbers in increasing order.

**Input** (`input.txt`): n (1 ≤ n ≤ 30000), the two points of the line, then n lines `x y r`; all values are integers up to 10000 in absolute value.
**Output** (`output.txt`): the count, then the numbers of the destroyed saucers.

Examples: `2` / `0 0 1 1` / `2 2 100` / `1000 1000 1` → `2` / `1 2`.
