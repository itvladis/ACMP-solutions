# Digits

The plus-minus sum of a number is the sum of its digits taken with alternating signs, starting
with "+": for 764 it is 7-6+4. Remove exactly one digit from the given N-digit number so that the
plus-minus sum of the remaining digits is as large as possible, and print that sum.

**Input** (`input.txt`): a positive N-digit number (2 ≤ N ≤ 50).
**Output** (`output.txt`): the maximum plus-minus sum.

Examples: `764` → `3`, `6274861` → `14`.
