# Billy Bones' chest

In the first year Billy Bones put some gold coins into a chest. In the second year he took
some coins out, leaving fewer than there were. From the third year on, every year he added
as many coins as the chest held two years earlier. Knowing that in year X the chest held
exactly Y coins, find how many coins were there in the first and in the second year.

**Input** (`input.txt`): integers X and Y (3 ≤ X ≤ 20, 1 ≤ Y ≤ 32767).
**Output** (`output.txt`): the number of coins in the first and in the second year.

Examples: `6 25` → `5 2`.
