# Pebble game

There is a pile of N pebbles and two players. On a move a player splits the pile into two unequal
parts and takes the smaller one away; the larger part stays as the new pile. The player who cannot
move loses. Moving first, how many pebbles should you take to guarantee a win?

**Input** (`input.txt`): N (1 ≤ N ≤ 10^6).
**Output** (`output.txt`): the number of pebbles to take on the first move, or 0 if there is no winning move.

Examples: `7` → `3`.
