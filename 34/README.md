# Secret message

A message of n digits is given. The base number has k digits and appears in the message
at least twice (occurrences may overlap). Determine whether the message contains such a number,
i.e. whether some substring of length k occurs at least twice.

**Input** (`input.txt`): n (1 ≤ n ≤ 10^5) and k (1 ≤ k ≤ 5), then the string of n digits.
**Output** (`output.txt`): `YES` or `NO`.

Examples: `10 5 / 0123456789` → `NO`, `13 2 / 0123400056789` → `YES`.
