# Viruses

A rectangular grid of n×m cells is attacked by several viruses. Every time unit each
infected cell infects its neighbours by side. Find the time after which the whole grid is
infected.

**Input** (`input.txt`): n and m (1 ≤ n, m ≤ 3000); then k (1 ≤ k ≤ 10) followed by k pairs
of row and column of the initially infected cells.
**Output** (`output.txt`): the time needed to infect the whole grid.

Examples: `4 5` / `2 2 1 4 5` → `4`.
