# Triangular countries

A city is located at a given point, and there are k triangular countries. Find all
countries that the city lies strictly inside of.

**Input** (`input.txt`): the city coordinates, k (1 ≤ k ≤ 1000), then k lines with six integers — the triangle vertices (up to 10000 in absolute value).
**Output** (`output.txt`): the number of such countries, then their numbers in increasing order.

Examples: `0 1` / `2` / `-2 0 2 0 0 2` / `-3 0 3 0 0 3` → `2` / `1 2`, `0 2` with the same countries → `1` / `2`.
