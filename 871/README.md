# Car racing

A connected city has n crossroads and a list of m two-way roads, some of which may be
listed several times. Decide whether a circular track exists: a closed route that starts
and ends at the same crossroad and doesn't visit any crossroad twice.

**Input** (`input.txt`): n (1 ≤ n ≤ 1000) and m (0 ≤ m ≤ 10^5), then m pairs `u v`.
**Output** (`output.txt`): `YES` if such a track exists, otherwise `NO`.

Examples: `3 4 / 1 2 / 2 3 / 3 1 / 3 2` → `YES`, `2 3 / 1 2 / 2 1 / 2 1` → `NO`.
