# Black and white graphics

Two black-and-white images of size w×h are given as tables of zeros and ones. A logical
operation of two arguments is given by its truth table. Apply the operation pixel by pixel to the
two images and print the resulting image.

**Input** (`input.txt`): w and h (1 ≤ w, h ≤ 100), then h rows of the first image, h rows of the second image, and finally
four digits: the operation's result for arguments (0,0), (0,1), (1,0) and (1,1).
**Output** (`output.txt`): the resulting image in the same format (h rows of w characters).

Examples: `5 3 / 01000 11110 01000 / 10110 00010 10110 / 0110` → `11110 / 11100 / 11110`.
