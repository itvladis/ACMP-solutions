# Power numbers

A number is a power number if it equals some integer raised to a power of at least 2 (for
example 4 = 2·2 and 27 = 3·3·3, but not 28). Check each given number.

**Input** (`input.txt`): n (1 ≤ n ≤ 10), then n numbers greater than 1 and less than 10^9.
**Output** (`output.txt`): `YES` or `NO` for every number on its own line.

Examples: `27 28` → `YES`, `NO`.
