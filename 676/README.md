# Matchstick game

Two players take turns removing matches from a pile: on each move a player takes exactly 1,
2 or 1000 matches. Whoever takes the last match wins. Determine who wins with optimal play.

**Input** (`input.txt`): the initial number of matches N (1 ≤ N ≤ 10000).
**Output** (`output.txt`): `1` if the first player wins, `2` otherwise.

Examples: `2` → `1`, `3` → `2`.
