# Knight moves

Given two cells of a chessboard, decide whether a knight can get from one to the other in
one move, and if not, whether it can do so in two moves.

**Input** (`input.txt`): two cells in standard notation separated by a comma and a space.
**Output** (`output.txt`): `1`, `2`, or `NO`.

Examples: `a1, h8` → `NO`, `a1, b3` → `1`, `a1, d4` → `2`.
