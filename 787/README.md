# Pawn game

A pawn stands in the bottom-left corner of an N×N board. Two players alternately move it one
cell up or one cell right. Numbers a1, ..., aN are written on the diagonal; as soon as the
pawn reaches it the game ends and the first player wins the number in that cell. Find the
amount the first player can guarantee with optimal play of both sides.

**Input** (`input.txt`): N (1 ≤ N ≤ 100), then a1, ..., aN (1 ≤ ai ≤ 100).
**Output** (`output.txt`): the guaranteed win of the first player.

Examples: `8` / `3 1 4 1 5 9 2 6` → `5`.
