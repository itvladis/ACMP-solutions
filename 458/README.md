# Cipher 2

A message without spaces is written column by column into a rectangle of height H, and then
its rows are read out in a given order to get the cipher. Given H, the row order and the
encoded text, restore the original message.

**Input** (`input.txt`): H (2 ≤ H ≤ 10), the order of rows, and the encoded message (CP866, up to 200 characters).
**Output** (`output.txt`): the decoded message.

Examples: `4 / 3 1 2 4 / ОМОИПРИАРАРНГМВЕ` → `ПРОГРАММИРОВАНИЕ`, `2 / 2 1 / ииафзк` → `физика`.
