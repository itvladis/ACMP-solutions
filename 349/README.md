# Prime numbers

Print all prime numbers from M to N inclusive.

**Input** (`input.txt`): two natural numbers M and N (2 ≤ M ≤ N ≤ 10^6).
**Output** (`output.txt`): the primes in increasing order, one per line, or `Absent` if there are none.

Examples: `2 5` → `2 / 3 / 5`, `4 4` → `Absent`.
