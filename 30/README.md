# Clock

An electronic clock shows time as hh:mm:ss. For a given time interval (both ends included),
count how many times each digit appears on the clock display.

**Input** (`input.txt`): the start and the end of the interval in `hh:mm:ss` format on two lines; the start is not later than the end.
**Output** (`output.txt`): 10 lines, the i-th one is the number of occurrences of digit i−1.

Examples: `23:59:58` / `23:59:59` → `0 0 2 2 0 4 0 0 1 3` (one per line).
