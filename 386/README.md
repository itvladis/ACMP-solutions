# Test generation

Construct N distinct points with integer coordinates not exceeding 10000 in absolute
value such that no three of them lie on one line.

**Input** (`input.txt`): an integer N (1 ≤ N ≤ 300).
**Output** (`output.txt`): `YES` followed by N lines with point coordinates, or `NO` if it is impossible.

Examples: `1` → `YES / 0 0`, `4` → `YES / 0 0 / 0 1 / 1 0 / 1 1`.
