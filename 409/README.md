# Railway

The ground along a future railway is measured every metre, and between neighbouring points the
surface is a straight line. The ground has to be levelled using only its own soil, without bringing
or removing any. Find the height at which the levelled surface (and the road) will lie.

**Input** (`input.txt`): the number N (1 < N ≤ 30000) of measurements, then N non-negative integer heights not exceeding 10000.
**Output** (`output.txt`): the resulting height with an accuracy of at least 10^-5.

Examples: `4 / 0 1 1 0` → `0.6666666667`, `5 / 2 2 2 2 2` → `2.0000000000`.
