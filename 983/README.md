# Running down the escalator

N people run down an escalator; person i needs t_i seconds per step and has w_i steps left. Overtaking is
forbidden: whoever catches up with a slower runner continues at that runner's speed, and several people
can stand on one step. Find when each person leaves the escalator.

**Input** (`input.txt`): N (1 ≤ N ≤ 10^5), then N pairs t_i, w_i (1 ≤ t_i, w_i ≤ 10^6), all w_i distinct.
**Output** (`output.txt`): the finishing time of each person, one per line, in input order.

Examples: `3` / `2 10` / `3 11` / `1 12` → `20` / `33` / `33`.
