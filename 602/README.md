# Points on a line

N distinct integer points are marked on a line. Find a segment of length L containing M ≥ 2 of
the points (endpoints count) such that L / M is as small as possible, and print its ends.

**Input** (`input.txt`): N (2 ≤ N ≤ 10000), then N integer coordinates with |Xi| ≤ 30000 in increasing order.
**Output** (`output.txt`): the coordinates of the segment ends A < B.

Examples: `3` / `-2 -1 1` → `-2 -1`.
