# Program template

Typing each key costs energy: a lowercase letter costs the digit sum of its position in
the alphabet, an uppercase letter costs 10 more (Shift), a space costs 4, a digit x costs
13 − x, a dot 5, a semicolon 7, a comma 2, `=`, `+`, `-` and quotes 3 each, round brackets
1 each, curly, square and angle brackets 8 each, and line breaks are free. Find the total
energy needed to type the given text.

**Input** (`input.txt`): the template text (up to 20000 bytes).
**Output** (`output.txt`): the total energy.

Examples: `abCD '+=1;2,3."()[]{}` → `127`.
