# Cutlets

A frying pan holds k cutlets at once. Each side of a cutlet must be fried for m minutes
without interruption. Find the minimum time needed to fry n cutlets on both sides.

**Input** (`input.txt`): three natural numbers k, m, n, each not exceeding 30000.
**Output** (`output.txt`): the minimum total frying time.

Examples: `1 1 1` → `2`, `2 2 1` → `4`.
