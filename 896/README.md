# Cake - 2

There will be either M or N people at a birthday party, counting the host. Find the minimum number
of pieces (not necessarily equal) to cut a cake into, so that in either case everyone can get the
same amount of cake.

**Input** (`input.txt`): two natural numbers M and N (1 ≤ M, N ≤ 30000).
**Output** (`output.txt`): the minimum number of pieces.

Examples: `2 3` → `4`.
