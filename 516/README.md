# 2-prime number

A number is called 2-prime if both numbers formed by its digits sorted in ascending order
and in descending order are prime. Determine whether the given number is 2-prime.

**Input** (`input.txt`): a natural number N (N ≤ 10^9).
**Output** (`output.txt`): `Yes` if N is 2-prime, otherwise `No`.

Examples: `13` → `Yes`, `23` → `No`.
