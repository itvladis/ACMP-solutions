# Gnomes' entertainment

Given a date D/M/Y in decimal, write each of its three parts in base D+1 and print the date in the
same D/M/Y format. Digits above 9 are written as capital English letters A, B, C, ...

**Input** (`input.txt`): a date D/M/Y (1 <= D <= 31, 1 <= M <= 12, 1 <= Y <= 9999).
**Output** (`output.txt`): the same date with every part written in base D+1.

Examples: `1/10/2000` → `1/1010/11111010000`.
