# Commercial calculator

A calculator charges 5% of the result for every addition it performs. N natural numbers have to be
summed, and the order of additions can be chosen freely. Find the minimal total cost of computing
the sum.

**Input** (`input.txt`): N (2 ≤ N ≤ 100000) and then N natural numbers, each at most 10000.
**Output** (`output.txt`): the minimal cost with exactly two digits after the decimal point.

Examples: `4` / `10 11 12 13` → `4.60`, `2` / `1 1` → `0.10`.
