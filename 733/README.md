# Sequence - 2

Vasya wrote n integers on a board. Petya may erase any number that has a strictly greater number
somewhere to its left and a strictly greater number somewhere to its right, and he keeps erasing
while possible. Print the sequence that remains.

**Input** (`input.txt`): n (1 ≤ n ≤ 10000), then n integers with |ai| ≤ 10^6.
**Output** (`output.txt`): the count k of remaining numbers, and the numbers themselves on the next line.

Examples: `12` / `1 2 3 2 4 1 3 4 2 3 2 1` → `8` / `1 2 3 4 4 3 2 1`.
