# Even-odd problem

Given n numbers, select the even ones whose third digit from the right in octal notation is
odd. Sort the selected numbers in non-decreasing order and print them.

**Input** (`input.txt`): n (1 ≤ n ≤ 10^5), then n integers a_i (64 ≤ a_i ≤ 10^9).
**Output** (`output.txt`): the count k of selected numbers on the first line, and the numbers themselves on the second line.

Examples: `4 / 100 64 64 130` → `3 / 64 64 100`, `3 / 128 129 130` → `0`.
