# Birthdays

Two classmates, Petya and Vasya, were born in 1993 or 1994, and Petya is older. Given both
birthdays, find by how many days Petya is older than Vasya. Both years are not leap years.

**Input** (`input.txt`): Petya's birthday on the first line and Vasya's on the second, in the format `DD.MM.YY`.
**Output** (`output.txt`): the number of days.

Examples: `01.01.93 / 02.01.93` → `1`, `05.02.94 / 05.03.94` → `28`.
