# Lawn

A grass tuft grows at every integer point of the plane. An axis-parallel rectangle with
opposite corners (x1, y1) and (x2, y2) was mowed, borders included, and a sprinkler at
(x3, y3) waters all points within distance r. Count the tufts that were both mowed and watered.

**Input** (`input.txt`): x1 y1 x2 y2 on the first line, x3 y3 r on the second (coordinates up to 10^5 in absolute value, 1 ≤ r ≤ 10^5).
**Output** (`output.txt`): the number of such points.

Examples: `0 0 5 4` / `4 0 3` → `14`.
