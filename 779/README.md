# Building a school

All houses of a village stand at integer points of a line. The school may be built at any
integer point (even where a house stands, since it goes on the other side of the street).
Choose the point that minimizes the total distance from all students' houses to the
school; if several points are optimal, take the largest one.

**Input** (`input.txt`): N (1 ≤ N ≤ 100000), then N strictly increasing house coordinates
(integers with absolute value up to 2·10^9).
**Output** (`output.txt`): the coordinate of the school.

Examples: `1 2 3 4` → `3`, `-1 0 1` → `0`.
