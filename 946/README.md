# Shelf

Discs are placed on a shelf and removed only at its left or right end. Operations `1 x` and
`2 x` put disc x at the left or right end, operations `3` and `4` remove a disc from the
left or right end. For every removal output the number of the removed disc.

**Input** (`input.txt`): N (1 ≤ N ≤ 10000), then N operations (always valid).
**Output** (`output.txt`): the numbers of removed discs separated by spaces.

Examples: `1 1`, `2 2`, `1 3`, `3`, `4` → `3 2`; `1 1`, `3` → `1`.
