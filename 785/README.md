# Automorphic numbers

A number is automorphic if its square ends with the number itself (for example, 25² = 625).
Print all automorphic numbers in the range [a, b].

**Input** (`input.txt`): two natural numbers a and b (a ≤ b ≤ 10^6).
**Output** (`output.txt`): all automorphic numbers from the range in increasing order, separated by spaces.

Examples: `1 10` → `1 5 6`.
