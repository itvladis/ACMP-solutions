# Number in a sequence

The sequence 011212201220... starts with 0, and then the whole written part is repeatedly appended with
every digit replaced (0 → 1, 1 → 2, 2 → 0). Find the digit at position N.

**Input** (`input.txt`): N (1 ≤ N ≤ 2147483647).
**Output** (`output.txt`): the digit at position N.

Examples: `1` → `0`, `10` → `2`.
