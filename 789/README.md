# Sequence 3

The sequence is built by the rules: 1 belongs to it, and if a belongs to it then 2a, 3a and
5a belong too; nothing else belongs. Find the n-th element of this sequence sorted in
strictly increasing order.

**Input** (`input.txt`): a natural number n (n ≤ 10000).
**Output** (`output.txt`): the n-th element.

Examples: `2` → `2`, `9` → `10`.
