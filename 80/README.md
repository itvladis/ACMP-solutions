# Identity

Vasya wrote an equality in his homework. A correct record is: a number, an operation
(`+`, `-`, `*`, `/`), a number, `=`, a number, with no spaces; a number is one or more
decimal digits optionally preceded by a single minus sign. Check whether the record is
well-formed and, if so, whether the equality actually holds.

**Input** (`input.txt`): a single line of up to 100 characters (possibly empty); all numbers are at most 30000 in absolute value.
**Output** (`output.txt`): `YES` if the equality is true, `NO` if it is well-formed but false, `ERROR` if the record is malformed.

Examples: `2+3=5` → `YES`, `3*7=20` → `NO`, `two plus three is five` → `ERROR`.
