# Fishermen

N fishermen caught X fish and went to sleep. In the morning they wake up one after
another, and each of them, unaware that the others have already left, splits the
remaining fish into N equal parts. Every time exactly K fish are left over, so he throws
those K fish into the sea, takes one part and goes home. For the given N and K find the
smallest positive X for which this is possible.

**Input** (`input.txt`): two integers N and K (2 ≤ N ≤ 8, 0 < K < N).
**Output** (`output.txt`): the minimal possible number of fish X.

Examples: `3 1` → `25`, `4 3` → `247`.
