# Equation in a base

A string A of digits and uppercase letters (letters stand for digits 10..35) is given
together with a number B. Find the smallest base X (up to 36) in which A represents B,
or report that there is none.

**Input** (`input.txt`): A on the first line, B (1 ≤ B ≤ 10^7) on the second.
**Output** (`output.txt`): the smallest suitable base, or 0 if there is none.

Examples: `A1 / 161` → `16`, `201 / 26` → `0`.
