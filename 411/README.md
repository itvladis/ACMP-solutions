# Quadratic equation

Solve the equation ax² + bx + c = 0 for the given integer coefficients.

**Input** (`input.txt`): three integers a, b, c, each at most 30000 in absolute value.
**Output** (`output.txt`): the number of distinct real roots, then the roots one per line with error at most 10^-4; `-1` if there are infinitely many roots.

Examples: `1 -3 2` → `2 / 1.000000 / 2.000000`, `0 -1 6` → `1 / 6.000000`.
