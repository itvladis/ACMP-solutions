# School algebra

The trinomial a + bx + cy is defined by its coefficients a, b and c. Print it using the usual
algebraic conventions: a coefficient with absolute value 1 is not written before a variable,
terms with a zero coefficient are dropped (if all are zero, print just 0), no "+" is written before
a negative coefficient or at the very beginning, and no multiplication sign is used. The order of
the terms must stay the same.

**Input** (`input.txt`): integers a, b and c, each at most 30000 in absolute value.
**Output** (`output.txt`): the trinomial written by these rules.

Examples: `0 2 -1` → `2x-y`, `3 0 -2` → `3-2y`.
