# N-gon wheel

A wheel has the shape of a regular N-gon with side A. Its quality index is the difference
between the circumradius and the inradius, and the wheel is good if this index is less
than one. Decide whether the wheel is good.

**Input** (`input.txt`): two natural numbers N and A (3 ≤ N ≤ 1000, 1 ≤ A ≤ 1000).
**Output** (`output.txt`): `YES` if the wheel is good, `NO` otherwise.

Examples: `3 1` → `YES`, `239 566` → `NO`.
