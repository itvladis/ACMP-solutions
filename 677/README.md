# Number of olympiad participants

Like Pythagoras describing his students, the olympiad secretary says: a K-th part of
the participants started solving the first problem, an M-th part the second one, an
N-th part the third one, and D more participants are still deciding where to start.
Find the number of participants, or output -1 if the secretary made a mistake (no
suitable whole number exists).

**Input** (`input.txt`): four integers K, N, M, D (1 ≤ K, N, M, D ≤ 100).
**Output** (`output.txt`): the number of participants or `-1`.

Examples: `2 4 7 3` → `28`, `2 2 2 3` → `-1`.
