# Professor

A professor reads a lecture so fast that the pauses between words can't be heard, so the
lecture is known only as a string of n lowercase English letters. Count how many different
words of length m the professor could have used, i.e. the number of distinct substrings of
length m in the text.

**Input** (`input.txt`): two numbers n and m (1 ≤ m ≤ n ≤ 100), then a string of n lowercase letters.
**Output** (`output.txt`): the number of distinct substrings of length m.

Examples: `3 1 / abc` → `3`, `10 3 / bbaabbbabb` → `6`.
