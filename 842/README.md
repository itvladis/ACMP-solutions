# Division-2

Determine whether the decimal expansion of 1/N is periodic (infinite) or finite.

**Input** (`input.txt`): a natural number N ≤ 10^18.
**Output** (`output.txt`): `YES` if 1/N has a period, otherwise `NO`.

Examples: `2` → `NO`, `3` → `YES`.
