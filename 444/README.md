# List

Given a multiset of integers, build the shortest text representation of the set of its
values: numbers and ranges `a, ..., b` separated by `, `, all in increasing order.
A range stands for every integer from a to b.

**Input** (`input.txt`): N (1 ≤ N ≤ 1000) and then N integers with absolute value up to 10000.
**Output** (`output.txt`): one of the shortest representations.

Examples: `7 / 1 3 5 -1 1 4 6` → `-1, 1, 3, ..., 6`.
