# Experiment

There are n numbered flasks with gases. Scientists connect pairs of flasks with tubes; when
gases meet, the one that started in the flask with the larger number wins and fills all the
connected space. After all connections, print every surviving gas with the volume it occupies.

**Input** (`input.txt`): n and m (0 < n ≤ 10, 0 ≤ m ≤ 15), the n flask volumes, then m pairs of connected flasks.
**Output** (`output.txt`): lines `gas volume` in increasing order of gas number.

Examples: `5 3` / `10 10 10 10 10` / `1 2` / `2 3` / `4 5` → `3 30` / `5 20`.
