# List of subjects

A student's notes list subjects, possibly repeated and possibly abbreviated by dropping
some trailing letters (`algebra` may appear as `alg` or `algeb`). Find how many different
subjects were taught; the data guarantees the answer is unambiguous.

**Input** (`input.txt`): N (1 ≤ N ≤ 10000), then N strings of lowercase letters and
underscores (length 2 to 20).
**Output** (`output.txt`): the number of subjects.

Examples: `algebra algeb history` → `2`, `algebr alg algebra algeb` → `1`.
