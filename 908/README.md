# Number 3

A natural number N can be decreased by one, divided by three if divisible by three, or
divided by two if even. Find the minimum number of operations needed to reach 1.

**Input** (`input.txt`): N (N ≤ 10^6).
**Output** (`output.txt`): the minimum number of operations.

Examples: `5` → `3`, `1` → `0`, `10` → `3`.
