# Sequence transformation

Find the value that occurs most often in a sequence (the smallest one if there is a tie) and move all
its occurrences to the end, keeping the order of the other elements.

**Input** (`input.txt`): n (1 ≤ n ≤ 200000), then n integers with absolute value up to 10^6.
**Output** (`output.txt`): the transformed sequence separated by spaces.

Examples: `7` / `1 2 3 2 3 1 2` → `1 3 3 1 2 2 2`.
