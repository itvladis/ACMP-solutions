# Maximum triple

In an N × N integer table pick three cells forming a chain: the first is adjacent
(horizontally or vertically) to the second, and the second to the third. Find the largest
possible sum of such three cells.

**Input** (`input.txt`): N (1 < N ≤ 2000), then N rows of N integers with absolute value at most 100.
**Output** (`output.txt`): the maximum sum.

Examples: `3` / `1 1 1` / `2 2 1` / `2 1 0` → `6`.
