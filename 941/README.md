# Unix

Write a calculator that adds two numbers written in the ternary numeral system and prints the
sum in decimal.

**Input** (`input.txt`): two numbers N and M in base 3 (0 ≤ N, M ≤ 2^31 − 1).
**Output** (`output.txt`): N + M in base 10.

Examples: `1 1` → `2`, `20 102` → `17`.
