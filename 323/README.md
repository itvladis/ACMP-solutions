# Goldbach's conjecture

Represent the given even number as a sum of two primes. Among all such pairs choose the one
containing the smallest prime.

**Input** (`input.txt`): an even number N (4 ≤ N ≤ 998).
**Output** (`output.txt`): the two primes, the smaller one first.

Examples: `6` → `3 3`, `992` → `73 919`.
