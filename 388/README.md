# Saddle points

A saddle point of a matrix is an element that is the minimum in its row and the maximum in
its column at the same time. Count the saddle points of an N × M matrix.

**Input** (`input.txt`): N and M (1 ≤ N, M ≤ 750), then N rows of M integers not exceeding 1000 in absolute value.
**Output** (`output.txt`): the number of saddle points.

Examples: `2 2 / 0 0 / 0 0` → `4`, `2 2 / 1 2 / 3 4` → `1`.
