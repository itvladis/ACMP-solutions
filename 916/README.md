# Economy

N bottles must be bought, the i-th costs C_i. At most K people can take part in the purchase,
and a person who has already bought X bottles pays (X+1)·C_i for bottle i. Find the minimum total
cost of buying all N bottles.

**Input** (`input.txt`): N and K (N, K ≤ 100) on the first line, then the prices C_1 ... C_N (C_i ≤ 10^6).
**Output** (`output.txt`): the minimum total cost.

Examples: `3 3` / `2 5 6` → `13`.
