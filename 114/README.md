# No two zeros in a row

Count the N-digit numbers in base K whose notation never contains two consecutive zeros
(the leading digit cannot be zero).

**Input** (`input.txt`): two integers N and K (2 ≤ K ≤ 10, 2 ≤ N, 4 ≤ N + K ≤ 18).
**Output** (`output.txt`): the count in decimal.

Examples: `2 10` → `90`, `4 2` → `5`, `6 3` → `328`.
