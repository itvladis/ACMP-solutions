# Choosing devices

Out of N devices exactly three must be selected. While a group has more than three devices,
they are numbered and either the even-numbered or the odd-numbered ones are kept. The process
stops when three or fewer remain; only a result of exactly three counts. Count the number of
ways to make the selection.

**Input** (`input.txt`): an integer N (1 ≤ N ≤ 2147483647).
**Output** (`output.txt`): the number of ways.

Examples: `3` → `1`, `6` → `2`.
