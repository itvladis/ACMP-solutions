# Hunter

A hunter stands at the origin of a shooting range with one bullet left. Targets are points
on the plane, and a single shot hits every target lying on the ray of the shot. Find the
largest number of targets that can be hit with one shot.

**Input** (`input.txt`): N (N ≤ 100), then N lines with integer coordinates x, y (-100 ≤ x, y ≤ 100); all points are distinct and none is at the origin.
**Output** (`output.txt`): the maximum number of targets hit by one shot.

Examples: `1 / 1 1` → `1`, `2 / 1 1 / 2 2` → `2`, `3 / 1 0 / 2 0 / 0 1` → `2`.
