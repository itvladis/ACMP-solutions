# Bertrand's postulate

Bertrand's postulate says that for every n > 1 there is a prime p with n < p < 2n. Count how
many such primes there are for the given n.

**Input** (`input.txt`): an integer n (2 ≤ n ≤ 50000).
**Output** (`output.txt`): the number of primes strictly between n and 2n.

Examples: `2` → `1`, `239` → `39`, `3000` → `353`.
