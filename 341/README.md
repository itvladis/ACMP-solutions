# Number sequence

The sequence starts with a1 = 0, and every next term is the smallest natural number greater
than the previous term whose decimal notation shares no digit with the previous term.
Given N, find the N-th term (it can be very long).

**Input** (`input.txt`): N (N ≤ 500).
**Output** (`output.txt`): the value aN.

Examples: `1` → `0`, `28` → `911`.
