# The hare and the tree

A dry tree stands inside a circular fence of radius R. After the branches are cut off, the
tree is a cylinder of radius r and height h, and its center is at distance b from the center
of the fence. The hare cuts it at the root and may fell it in any direction; the fallen trunk
lies so that its lower end touches the circle of the stump as a tangent. Determine whether
there is a direction in which the fallen tree does not damage the fence.

**Input** (`input.txt`): four integers R, r, h and b (r + b < R, 1 ≤ r ≤ R ≤ 100, 1 ≤ h ≤ 1000).
**Output** (`output.txt`): `YES` if such a direction exists, otherwise `NO`.

Examples: `90 3 50 10` → `YES`.
