# Dates

Print the day of the week and the date that come K days after January 1, 2008 (a Tuesday).

**Input** (`input.txt`): K (0 ≤ K ≤ 1000).
**Output** (`output.txt`): the date in the format `Weekday, DD.MM`.

Examples: `0` → `Tuesday, 01.01`, `5` → `Sunday, 06.01`.
