# Evolution

On a planet every species splits into exactly two new subspecies at each evolution step, and the
old species disappears. All species ever existing are numbered like a binary tree: the root is 1,
the children of species k are 2k and 2k + 1. Given the numbers of two species, find the number of
their nearest common ancestor.

**Input** (`input.txt`): N (1 ≤ N ≤ 60) — the number of evolution steps, then two species numbers.
**Output** (`output.txt`): the number of the nearest common ancestor.

Examples: `4` / `15` / `12` → `3`, `18` / `233016` / `233008` → `14563`.
