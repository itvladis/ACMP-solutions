# Coins - 2

There are N baskets of gold coins. All coins weigh w grams except those in one basket, which weigh
w-d grams. A wizard takes i coins from the i-th basket for i = 1..N-1 and none from the last one,
weighs them all together and gets P. Determine which basket holds the fake coins.

**Input** (`input.txt`): four integers N, w, d and P (2 ≤ N ≤ 8000, 1 ≤ d < w ≤ 30).
**Output** (`output.txt`): the number of the basket with fake coins.

Examples: `10 25 8 1109` → `2`, `10 25 8 1125` → `10`, `8000 30 12 959879400` → `50`.
