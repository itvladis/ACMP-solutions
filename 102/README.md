# Triangle and point

Given the three vertices of a triangle and one more point on the plane, determine whether
the point belongs to the triangle. A point lying on a side or at a vertex counts as
belonging to it.

**Input** (`input.txt`): four lines with integer coordinate pairs — three triangle vertices and the tested point (|coordinates| ≤ 10000).
**Output** (`output.txt`): `In` if the point belongs to the triangle, otherwise `Out`.

Examples: `0 0 / 100 0 / 0 100 / 100 100` → `Out`, `0 0 / 100 0 / 0 100 / 10 10` → `In`, `0 0 / 100 0 / 0 100 / 0 0` → `In`.
