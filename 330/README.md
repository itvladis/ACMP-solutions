# Teleportation

A spaceship on an infinite plane can teleport in one second from (x, y) to any of
(x+C, y+C), (x+C, y−C), (x−C, y+C), (x−C, y−C), where C is any natural number chosen
anew for every jump. Find the minimum time to get from (x1, y1) to (x2, y2), or report
that it is impossible.

**Input** (`input.txt`): x1 y1 on the first line and x2 y2 on the second (integers from 0
to 10^6, the points are different).
**Output** (`output.txt`): the minimum number of jumps, or `0` if the target is unreachable.

Examples: `0 0` / `0 2` → `2`.
