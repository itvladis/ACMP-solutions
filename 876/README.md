# Optimization on a circle

Maximize f(x, y) = Ax + By subject to x² + y² = R², and report the point where the
maximum is reached.

**Input** (`input.txt`): three real numbers A, B, R (1 ≤ A, B, R ≤ 10).
**Output** (`output.txt`): the maximum value on the first line and the coordinates x0, y0 on the second, with precision 10^-5.

Examples: `1 1 1` → `1.414213562373 / 0.707106781187 0.707106781187`, `2.0 1.0 1.0` → `2.236067977500 / 0.894427191000 0.447213595500`.
