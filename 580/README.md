# Tray

Check whether a round plate of radius r fits on a triangular tray with the given side lengths.

**Input** (`input.txt`): three side lengths of the tray (a valid triangle), then the radius; all numbers are positive integers up to 100.
**Output** (`output.txt`): `YES` or `NO`.

Examples: `1 1 1` / `1` → `NO`, `3 4 5` / `1` → `YES`.
