# Alien attack

Every alien ship is an isosceles right triangle whose right-angle vertex (the nose) is at
(x, y) and whose legs of length s point strictly south and west. Find the area of the
region covered by all ships at once.

**Input** (`input.txt`): n (1 ≤ n ≤ 100), then n lines `x y s` (|x|, |y| ≤ 10^5, 0 < s ≤ 1000).
**Output** (`output.txt`): the area with three digits after the decimal point.

Examples: `3` / `2 4 6` / `4 2 7` / `3 3 5` → `4.500`.
