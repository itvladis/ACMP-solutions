# Word chain

A word chain is a sequence of words where each word is a proper prefix of the next one.
Given a set of words, find the maximum length of a chain that can be built from (some of)
these words.

**Input** (`input.txt`): M (1 ≤ M ≤ 255), then M non-empty words of lowercase English letters, each up to 255 characters long.
**Output** (`output.txt`): the maximum chain length.

Examples: `3 / a / ab / abc` → `3`, `5 / a / ab / bc / bcd / add` → `2`.
