# Diplomas

Petya has n diplomas, all of size w by h. He wants to pin them, without rotating and without
overlapping, onto a square board. Find the smallest possible side length of the board.

**Input** (`input.txt`): three integers w, h, n (1 ≤ w, h, n ≤ 10^9).
**Output** (`output.txt`): the minimal side of the square board.

Examples: `2 3 10` → `9`.
