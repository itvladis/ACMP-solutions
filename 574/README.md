# Anagrams

A string S1 is an anagram of S2 if it can be obtained by rearranging the characters of S2.
Check whether S1 is an anagram of S2.

**Input** (`input.txt`): two lines S1 and S2 of uppercase English letters, each non-empty and at most 100000 characters long.
**Output** (`output.txt`): `YES` if S1 is an anagram of S2, otherwise `NO`.

Examples: `ABAA / ABBA` → `NO`, `ABBA / BABA` → `YES`.
