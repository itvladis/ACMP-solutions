# Funny sequence

The sequence is defined as a_1 = 1, and a_n = a_(n-1) + 3 if n has already appeared among the
previous terms, otherwise a_n = a_(n-1) + 2. The first terms are 1, 3, 6, 8, 10, 13, 15, 18.
Compute a_n.

**Input** (`input.txt`): an integer n (1 ≤ n ≤ 10^5).
**Output** (`output.txt`): the value a_n.

Examples: `1` → `1`, `8` → `18`.
