# Beautiful wall

An artist received K square marble tiles and wants to lay out a rectangle of H rows and W
columns on a wall (H·W ≤ K). The "ugliness" of a rectangle is |H - W| plus the number of unused
tiles K - H·W. Find the rectangle with the smallest ugliness; any optimal answer is accepted.

**Input** (`input.txt`): an integer K (1 ≤ K ≤ 10^6).
**Output** (`output.txt`): two numbers H and W.

Examples: `11` → `3 3`, `2` → `1 2`, `20` → `4 5`.
