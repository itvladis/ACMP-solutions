# Sum - 2

Given a natural number x, count the ways to write it as a sum of four natural numbers
x = a + b + c + d with a ≤ b ≤ c ≤ d.

**Input** (`input.txt`): an integer x (1 ≤ x ≤ 1500).
**Output** (`output.txt`): the number of such representations.

Examples: `3` → `0`, `5` → `1`.
