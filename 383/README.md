# Beautiful numbers - 2

A number is called beautiful if the sum of its decimal digits is divisible by the number
of its digits. Find the N-th beautiful number in increasing order.

**Input** (`input.txt`): an integer N (1 ≤ N ≤ 100 000).
**Output** (`output.txt`): the N-th beautiful number.

Examples: `1` → `1`, `15` → `20`.
