# Gambling Shrek

There are N cards (N is even) with positive numbers. The player takes exactly N/2 cards, the
dealer gets the rest, and the player wins the difference between his sum and the dealer's sum.
Shrek can see the numbers through the cards. Find the largest win he can get.

**Input** (`input.txt`): an even N (2 ≤ N ≤ 100), then N numbers (1 ≤ Ai ≤ 10^6).
**Output** (`output.txt`): the maximum possible win.

Examples: `2 / 1 3` → `2`, `4 / 3 1 8 100` → `104`.
