# Computer game

A hero jumps over platforms from left to right. Jumping to the neighbouring platform costs
|y2 − y1| energy, and a super jump over one platform costs 3·|y3 − y1|. Find the minimum energy
needed to get from the first platform to the last one.

**Input** (`input.txt`): n (1 ≤ n ≤ 30000), then n platform heights (natural numbers up to 30000).
**Output** (`output.txt`): the minimum total energy.

Examples: `3 / 1 5 10` → `9`, `3 / 1 5 2` → `3`.
