# Box

Six rectangular wooden boards are given by their width and height. Determine whether a
rectangular box (parallelepiped) can be assembled from them, each board forming one face.

**Input** (`input.txt`): six lines, each with two integers w and h (1 ≤ w, h ≤ 10000).
**Output** (`output.txt`): `POSSIBLE` or `IMPOSSIBLE`.

Examples: the first sample (boards 1345×2584, 2584×683, ...) → `POSSIBLE`, the second → `IMPOSSIBLE`.
