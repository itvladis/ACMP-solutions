# Prime digital root

The prime digital root of N is N itself if N is prime; it is 0 if N is a one-digit
non-prime number; otherwise it is the prime digital root of the digit sum of N. Find it.

**Input** (`input.txt`): N (1 ≤ N ≤ 2^31 − 1).
**Output** (`output.txt`): the prime digital root of N.

Examples: `1` → `0`, `3` → `3`, `128` → `11`.
