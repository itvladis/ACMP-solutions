# Lexicographic order of numbers

The numbers from 1 to N are sorted lexicographically as strings (for N = 25: 1, 10, 11,
..., 19, 2, 20, ..., 25, 3, ..., 9). Find the position of K in this order.

**Input** (`input.txt`): N and K (1 ≤ K ≤ N ≤ 10^4).
**Output** (`output.txt`): the position of K.

Examples: `25 17` → `9`.
