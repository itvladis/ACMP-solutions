# N-digit numbers

Count the N-digit numbers whose digit sum equals their digit product, and find the smallest such
number.

**Input** (`input.txt`): a natural number N ≤ 10.
**Output** (`output.txt`): the count and the smallest number separated by a space.

Examples: `1` → `10 0`, `2` → `1 22`.
