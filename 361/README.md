# Substrings of the same letters

In a string of lowercase English letters, find two substrings starting at different
positions that consist of exactly the same letters (possibly in a different order), and
make them as long as possible. For example, in `twotwow` these are `wotwo` and `otwow`.

**Input** (`input.txt`): the string, 1 to 100 characters long.
**Output** (`output.txt`): the length of the substrings in the best pair, or 0 if there is no such pair.

Examples: `abcde` → `0`, `abcdea` → `5`.
