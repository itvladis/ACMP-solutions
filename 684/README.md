# Checkers - 2

A white checker stands on a black square of an 8×8 board. It moves diagonally one square forward
(up), never backwards, and never becomes a king. Determine whether it can reach the given square.

**Input** (`input.txt`): the start square and the target square in chess notation, separated by a space.
**Output** (`output.txt`): `YES` if the target square is reachable, otherwise `NO`.

Examples: `a1 b2` → `YES`, `b2 a1` → `NO`, `a1 h7` → `NO`, `a1 h8` → `YES`.
