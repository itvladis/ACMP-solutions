# Minimal number

Two natural numbers are given. Merge their digits into one number, keeping the original order
of digits from each number, so that the result is as small as possible.

**Input** (`input.txt`): two natural numbers, each on its own line, less than 10^255.
**Output** (`output.txt`): the smallest number that can be obtained.

Examples: `125 / 34` → `12345`.
