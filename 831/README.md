# Primes again

Among the primes in the segment [a, b], find the one with the largest digit sum. If several
primes share that sum, pick the largest of them.

**Input** (`input.txt`): two integers a and b (1 ≤ a ≤ b ≤ 10^8, b − a ≤ 1000).
**Output** (`output.txt`): the required prime, or -1 if the segment contains no primes.

Examples: `1 13` → `7`, `900 1000` → `997`, `8 10` → `-1`.
