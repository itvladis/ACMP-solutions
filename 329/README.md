# Staircase 2

Vova stands before a staircase of N steps with an integer written on each. Each move he
goes up one step or jumps over one step, and he must finish on step N. Find the route that
maximizes the sum of the numbers on the visited steps.

**Input** (`input.txt`): N (2 ≤ N ≤ 1000), then N integers with absolute value at most 1000.
**Output** (`output.txt`): the maximum sum, then the visited step numbers in increasing order (any optimal route).

Examples: `3 / 1 2 1` → `4 / 1 2 3`, `3 / 1 -1 1` → `2 / 1 3`.
