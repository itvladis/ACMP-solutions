# Java vs C++

In Java style a variable name starts with a lowercase word and every next word starts with a capital
letter (`javaIdentifier`); in C++ style words are lowercase and separated by single underscores
(`java_identifier`). Convert a name from one style into the other, or report that it fits neither.

**Input** (`input.txt`): a name of 1 to 100 characters (English letters and underscores).
**Output** (`output.txt`): the converted name, or `Error!`.

Examples: `long_and_mnemonic_identifier` → `longAndMnemonicIdentifier`, `anotherExample` → `another_example`,
`i` → `i`, `bad_Style` → `Error!`.
