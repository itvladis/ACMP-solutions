# Anagram 2

Two words are given. The second one is a correct anagram of the first if it is made by
rearranging the letters of the first word so that every single letter ends up in a different
position (no position keeps the same letter). Check whether the anagram is correct.

**Input** (`input.txt`): two lowercase English words (1 to 20 letters each) separated by a space.
**Output** (`output.txt`): `YES` if the anagram is correct, otherwise `NO`.

Examples: `post stop` → `YES`, `post pots` → `NO`, `aabb aabb` → `NO`.
