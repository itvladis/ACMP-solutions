# Points and lines

Given N points and a number M, decide whether the points can be joined by M segments, each connecting two
different points with at most one segment per pair, so that the resulting graph is not connected.

**Input** (`input.txt`): K (1 ≤ K ≤ 1000), then K lines with N (1 ≤ N ≤ 10^9) and M (0 ≤ M ≤ 10^9).
**Output** (`output.txt`): `Yes` or `No` for each test on a separate line.

Examples: `2` / `2 0` / `2 2` → `Yes` / `No`.
