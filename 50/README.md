# Strings

Given two strings a and b, count how many substrings of a (taken at different positions) are
cyclic shifts of b.

**Input** (`input.txt`): string a (1 ≤ |a| ≤ 1000) on the first line and string b (1 ≤ |b| ≤ min(100, |a|)) on the second; both consist of English letters and digits.
**Output** (`output.txt`): the number of such substrings.

Examples: `abcabc` / `abc` → `4`, `abcabc` / `acb` → `0`, `aaaaaaa` / `aa` → `6`, `aAaa8aaAa` / `aAa` → `4`.
