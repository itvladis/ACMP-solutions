# Numeral system

Consider a base-3 positional system that uses the digits 1, 2 and 3 instead of 0, 1 and 2.
For example, 7 = 2·3 + 1 is written as `21`, and 22 = 2·9 + 1·3 + 1 is written as `211`.
Write the given number n in this system.

**Input** (`input.txt`): a natural number n (1 ≤ n ≤ 2·10⁹).
**Output** (`output.txt`): n written in this system.

Examples: `7` → `21`, `22` → `211`.
