# Event

Given the start and end dates of an event, find its length in days, counting both the
first and the last day and taking leap years into account (a year is leap if it is
divisible by 4 but not by 100, or divisible by 400).

**Input** (`input.txt`): two dates in `DD.MM.YYYY` format; the first is earlier.
**Output** (`output.txt`): the length of the event in days.

Examples: `01.09.2005` / `06.10.2005` → `36`, `01.09.0005` / `01.09.0006` → `366`,
`01.02.2004` / `01.03.2004` → `30`.
