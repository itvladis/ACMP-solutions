# Working time

A man writes the start and end time of every task on separate sheets; tasks never overlap, a task starts
at the beginning of its start minute and ends at the end of its end minute, and he works every day from
10:00 to 18:00. The sheets got shuffled. Find the total working time over the (non-leap) year.

**Input** (`input.txt`): an even K (K ≤ 5000), then K lines in the format `DD.MM. hh:mm`.
**Output** (`output.txt`): the total time as `h:mm`.

Examples: `4` / `15.01. 17:00` / `16.01. 12:00` / `11.02. 14:00` / `30.01. 10:00` → `103:02`.
