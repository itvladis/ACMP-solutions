# Robot community

At the start of each year robots form groups of three or five; in a year a group of three
builds 5 new robots and a group of five builds 9. Groups are formed so that the number of
new robots is maximal. Every robot lives exactly three years after it is built. At the
start of the first year there are K freshly built robots. Find the number of robots at
the start of year N.

**Input** (`input.txt`): K (1 ≤ K ≤ 500) and N (1 ≤ N ≤ 100).
**Output** (`output.txt`): the number of robots at the start of year N.

Examples: `3 2` → `8`, `8 2` → `22`.
