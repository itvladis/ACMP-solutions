# Alphabet

There are 26 kids, and each knows the English alphabet only up to some letter. They stand in a row,
and the i-th kid has to name the i-th letter, so he must know the alphabet at least up to it.
Find an arrangement of the kids that works, or report that none exists.

**Input** (`input.txt`): a string of 26 capital letters; the i-th letter is how far the i-th kid knows the alphabet.
**Output** (`output.txt`): `YES` and a permutation of 1..26 (the order of kids in the row) on the next line, or `NO`. Any valid permutation is accepted.

Examples: `ABCDEFGHIJKLMNOPQRSTUVWXYZ` → `YES` / `1 2 ... 26`, `AAZZZZZZZZZZZZZZZZZZZZZZZZ` → `NO`.
