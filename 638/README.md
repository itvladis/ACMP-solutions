# All-Russian olympiad in informatics

A month has n days and a week has w days; the first day of the month falls on weekday s.
Some weekdays are forbidden every week, and some specific days of the month are forbidden
as well. Count the ways to choose k consecutive days that contain no forbidden day.

**Input** (`input.txt`): n k (1 ≤ k ≤ n ≤ 100000); w, dw, s; the dw forbidden weekdays; dm; the dm forbidden days of the month.
**Output** (`output.txt`): the number of valid choices.

Examples: `31 3 / 7 1 7 / 7 / 2 / 1 9` → `15`.
