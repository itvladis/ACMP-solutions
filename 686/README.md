# Bell

Rearrange an array of n integers like a bell: the smallest element goes to the first position,
the next smallest to the last position, the next one to the second position, the next one to the
second-to-last position, and so on towards the middle.

**Input** (`input.txt`): n (1 <= n <= 30000) on the first line, the array elements (|a_i| <= 32767) on the second.
**Output** (`output.txt`): the rearranged array, space separated.

Examples: `5 / 1 2 3 4 5` → `1 3 5 4 2`.
