# Castle

A castle has K levels. Each level is a regular N-gon, and all levels share one common
corner (each next polygon is a bigger copy growing from that corner). On every side of
the first level there are two rooms (at the corners), and each next level has one more
room per side than the previous one. Rooms that coincide are counted once. Find the total
number of rooms in the castle.

**Input** (`input.txt`): two integers N and K (3 ≤ N ≤ 10^6, 1 ≤ K ≤ 10^6).
**Output** (`output.txt`): the number of rooms.

Examples: `6 3` → `28`.
