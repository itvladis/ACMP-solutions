# Puzzle

An N×N grid of letters and a list of keywords are given. Each keyword is found as a path of
side-adjacent cells and crossed out; used cells can't be reused. It is guaranteed that all
keywords can be crossed out. Print the letters that remain in the grid in alphabetical order.

**Input** (`input.txt`): N (1 ≤ N ≤ 10) and M (0 ≤ M ≤ 100), then N rows of uppercase letters and M keywords.
**Output** (`output.txt`): the remaining letters sorted alphabetically.

Examples: `3 2 / ISQ / ABC / IQW / I / IS` → `ABCQQW`.
