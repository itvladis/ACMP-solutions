# Building roads

There are N centers in a city, and every pair of them is either connected by a one-way road in one of
the two directions or not connected at all. Count the number of possible road layouts.

**Input** (`input.txt`): N (2 ≤ N ≤ 100).
**Output** (`output.txt`): the number of layouts.

Examples: `2` → `3`, `4` → `729`.
