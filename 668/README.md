# Zmey Gorynych

A dragon has N heads and M tails. Cutting one head makes it grow back, cutting one tail grows two tails,
cutting two tails grows one head, and cutting two heads grows nothing. Find the minimum number of strikes
needed to cut off all heads and tails.

**Input** (`input.txt`): N and M (0 ≤ N, M ≤ 1000).
**Output** (`output.txt`): the minimum number of strikes, or -1 if it is impossible.

Examples: `3 3` → `9`.
