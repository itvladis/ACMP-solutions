# Wheel of fortune

A drum is divided into sectors with numbers written on them. The host spun it and named
the numbers one after another; the drum made a whole number of turns, so the last number
is the same sector as the first. Find the smallest possible number of sectors on the drum.

**Input** (`input.txt`): N (2 ≤ N ≤ 30000), then N named numbers (natural, up to 32000);
the first and the last ones are equal.
**Output** (`output.txt`): the minimum number of sectors.

Examples: `5 3 1 3 5 2 5 3 1 3 5 2 5` → `6`, `1 1 1 1` → `1`, `1 2 3 1` → `3`.
