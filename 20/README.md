# Sawtooth sequence

A sequence is called sawtooth if its elements strictly alternate between going up and going
down (a1 < a2 > a3 < … or a1 > a2 < a3 > …). Find the length of the longest contiguous sawtooth
subsequence of the given sequence.

**Input** (`input.txt`): N, then N integers.
**Output** (`output.txt`): the length of the longest contiguous sawtooth subsequence.

Examples: `3 / 1 2 3` → `2`, `12 / 5 7 6 3 4 2 7 1 8 9 4 5` → `7`, `5 / 1 -2 3 -4 5` → `5`.
