# Bishop

A bishop stands on an 8 × 8 board. Determine whether it can reach the cell (x, y), the minimal number of
moves, and the intermediate cells of such a route.

**Input** (`input.txt`): four numbers m, n, x, y from 1 to 8 — the start cell and the target cell.
**Output** (`output.txt`): the minimal number of moves k followed by k - 1 lines with intermediate cells, or `0` if the cell is unreachable.

Examples: `1 1 3 1` → `2` / `2 2`, `1 1 3 3` → `1`, `1 1 4 1` → `0`.
