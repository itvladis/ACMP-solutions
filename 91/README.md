# Two sequences

The sequence a starts with 2, 3, 4, 7, 13, and for n > 5 a_n = b_{n−1} + b_{n−3}, where b is the
increasing sequence of all natural numbers that do not appear in a. Find a_n and b_n.

**Input** (`input.txt`): an integer n (1 ≤ n ≤ 10000).
**Output** (`output.txt`): a_n on the first line and b_n on the second.

Examples: `4` → `7` / `8`, `10` → `25` / `16`, `6578` → `19731` / `9868`.
