# Chessboard

A connected figure without holes was cut out of a chessboard along the cell borders.
Given the list of cells that form the figure, find its perimeter (a cell side has length 1).

**Input** (`input.txt`): the number N (1 ≤ N ≤ 64) of cut cells, then N lines with the row and column of each cell (from 1 to 8).
**Output** (`output.txt`): the perimeter of the figure.

Examples: `3 / 1 1 / 1 2 / 2 1` → `8`, `1 / 8 8` → `4`.
