# Antipalindrome

Given a string of lowercase English letters (length up to 100 000), find its longest
substring that is not a palindrome. If every substring is a palindrome, report that there is
no solution.

**Input** (`input.txt`): a non-empty string s.
**Output** (`output.txt`): the longest non-palindromic substring, or `NO SOLUTION`.

Examples: `abba` → `abb`, `abc` → `abc`, `aaaaa` → `NO SOLUTION`.
