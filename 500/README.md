# Agent

Agents can be partners only if no other agent's age lies strictly between theirs. Every agent must have at
least one partner, and in each pair only the older agent takes a risk. Choose pairs so that the total
risk is minimal.

**Input** (`input.txt`): N (2 ≤ N ≤ 10000), then N pairs: age (all different) and risk.
**Output** (`output.txt`): the minimal total risk.

Examples: `3` / `6000 2 5500 3 5000 4` → `5`, `5` / `5005 1 5004 2 5003 3 5002 4 5001 5` → `7`.
