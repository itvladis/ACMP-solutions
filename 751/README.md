# Money, money, money

Choose two banknote values a and b such that the sum x cannot be paid exactly with them,
but every sum greater than x can. If no such pair exists, output two zeros.

**Input** (`input.txt`): a natural number x ≤ 10^12.
**Output** (`output.txt`): two numbers a and b, or `0 0`.

Examples: `3` → `2 5`, `4` → `0 0`, `5` → `3 4`.
