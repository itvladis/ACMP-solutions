# Sequence transformation - 2

Given a sequence of n integers, find the value that occurs in it most often (if there
are several such values, take the smallest one). Move all occurrences of that value to
the end of the sequence while keeping the relative order of all other elements.

**Input** (`input.txt`): the number n (3 ≤ n ≤ 100), then n integers with absolute value at most 100.
**Output** (`output.txt`): the transformed sequence, space-separated.

Examples: `7` / `1 2 3 2 3 1 2` → `1 3 3 1 2 2 2`.
