# Brackets 2

A string consists of round and square brackets. In one move you may change an opening
bracket into the other opening bracket type, or a closing bracket into the other closing
type. Find the minimum number of moves to turn the string into a correct bracket sequence,
or report that it is impossible.

**Input** (`input.txt`): a string S of length up to 100000.
**Output** (`output.txt`): the minimum number of moves, or `-1`.

Examples: `(())[]` → `0`, `[(])` → `2`, `((]]]` → `-1`.
