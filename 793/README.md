# Smith numbers

A Smith number is a composite number whose digit sum equals the total digit sum of its prime
factors counted with multiplicity (for example, 202 = 2 · 101 and 2+0+2 = 2+1+0+1). For each
given number determine whether it is a Smith number.

**Input** (`input.txt`): at most 20 natural numbers from 4 to 10^6.
**Output** (`output.txt`): a string of 0s and 1s, where 1 means the corresponding number is a Smith number.

Examples: `4 20 17 202` → `1001`.
