# Code

Given a digit sum S and a number of digits K, print the largest and the smallest K-digit
numbers (without leading zeros) whose digits add up to S.

**Input** (`input.txt`): S and K (K ≤ 100); at least one such number exists.
**Output** (`output.txt`): the largest and the smallest number.

Examples: `1 3` → `100 100`, `2 3` → `200 101`, `3 4` → `3000 1002`.
