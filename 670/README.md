# Numbers without repeated digits

Write out the natural numbers in increasing order and remove every number that contains some
digit at least twice. Find the N-th number of the remaining sequence.

**Input** (`input.txt`): an integer N (1 ≤ N ≤ 10000).
**Output** (`output.txt`): the N-th number with all digits distinct.

Examples: `100` → `123`.
