# Josephus problem

N people numbered 1 to N stand in a circle. Counting around the circle, every K-th remaining
person is eliminated until only one is left. Find the number of the survivor.

**Input** (`input.txt`): two natural numbers N and K (N ≤ 500, K ≤ 100).
**Output** (`output.txt`): the number of the survivor.

Examples: `10 3` → `4`.
