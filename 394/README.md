# Oranges

Katya bought m identical oranges for her n guests. She wants to cut every orange into the same
number of equal slices so that all slices can be shared equally among the guests. Find the minimal
number of slices per orange.

**Input** (`input.txt`): two positive integers n and m (1 ≤ n, m ≤ 10^9).
**Output** (`output.txt`): the minimal number of slices each orange has to be cut into.

Examples: `2 5` → `2`, `2 4` → `1`.
