# Nails

Nails are driven into a straight board. Tie some pairs of nails with threads so that every nail has at
least one thread attached and the total thread length is minimal.

**Input** (`input.txt`): N (2 ≤ N ≤ 100), then N coordinates of the nails (non-negative integers up to 10000).
**Output** (`output.txt`): the minimal total thread length.

Examples: `6` / `3 4 12 6 14 13` → `5`.
