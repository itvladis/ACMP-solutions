# Floyd's algorithm

A complete directed weighted graph is given by its adjacency matrix with no negative cycles.
Build the matrix of shortest path lengths between all pairs of vertices.

**Input** (`input.txt`): N (1 ≤ N ≤ 100), then the N×N adjacency matrix.
**Output** (`output.txt`): the N×N matrix of shortest distances.

Examples: `4 / 0 5 9 100 / 100 0 2 8 / 100 100 0 7 / 4 100 100 0` → `0 5 7 13 / 12 0 2 8 / 11 16 0 7 / 4 9 11 0`.
