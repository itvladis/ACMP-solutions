# Round table

m boys and n girls sit around a round table. A boy is active only if both of his neighbours
are girls; a girl is active only if one of her neighbours is a boy and the other is a girl.
Find a seating that maximizes the number of active members.

**Input** (`input.txt`): two integers m and n (0 ≤ m, n ≤ 1000, m + n ≥ 3).
**Output** (`output.txt`): a string of m letters `B` and n letters `G` describing the seating
around the table (the first and the last characters are also neighbours).

Examples: `1 2` → `BGG`, `2 2` → `BGBG`.
