# Product of digits 2

Count the integers in the segment [L, R] that are divisible by the product of their digits.

**Input** (`input.txt`): two integers L and R (1 ≤ L ≤ R ≤ 10^9, R − L ≤ 10^5).
**Output** (`output.txt`): the required count.

Examples: `1 12` → `11`.
