# Number decomposition

Every natural number can be written as a sum of several consecutive natural numbers, e.g.
25 = 12 + 13 = 3 + 4 + 5 + 6 + 7. Find the largest possible number of terms in such a sum.

**Input** (`input.txt`): N (1 ≤ N ≤ 10^9).
**Output** (`output.txt`): the maximum number of terms.

Examples: `2` → `1`, `5` → `2`, `25` → `5`.
