# Tournament

A knockout tournament: each match is played by two players, the loser is out and the
winner advances, until one player remains and gets gold; silver goes to the opponent in
the final. If there are more than three participants, an extra match between the two
players eliminated last (excluding the finalists) decides the bronze. Find the minimal
number of matches needed to determine all medalists.

**Input** (`input.txt`): one integer N (0 ≤ N ≤ 2147483647) — the number of participants.
**Output** (`output.txt`): the minimal number of matches.

Examples: `3` → `2`, `4` → `4`.
