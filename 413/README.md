# Military base

A satellite image of a base is given as a grid of `.` and `#`. Every building is a filled square
with sides parallel to the image borders, and no two buildings share a piece of wall. Count the
buildings.

**Input** (`input.txt`): N and M (1 ≤ N, M ≤ 500), then N rows of M characters.
**Output** (`output.txt`): the number of buildings.

Examples: an 8×6 image with a 2×2 and a 3×3 square → `2`.
